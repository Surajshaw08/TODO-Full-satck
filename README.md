# 📝 MERN Todo App with OTP Auth & Stripe Subscription

A full-featured Todo application built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), featuring:

- ✅ User authentication with OTP (Email/SMS)
- 📋 CRUD operations for todos
- 💡 Free Plan (max 5 todos)
- 💳 Paid Plan (unlimited todos) via Stripe
- 🛡️ JWT-based authentication
- 🌐 Responsive UI with Tailwind CSS
- ⚙️ Environment-based configuration using `.env`
